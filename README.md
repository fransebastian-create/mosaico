# Mosaico

Planificador de grilla tipo Instagram: subís fotos y videos, los ves en una grilla de 3 columnas,
recortás en 4:5, girás, retocás el color sutilmente para emparejar la estética y descargás en 1080×1350.

- Funciona en el navegador (computadora y celular), sin instalar nada.
- Los originales nunca se modifican: los retoques se aplican una sola vez al descargar.
- Con la nube activada, el proyecto se guarda en una carpeta de Google Drive y se puede editar entre varias personas.

## Archivos

- `index.html`, `styles.css`, `app.js`: la app.
- `drive.js`: sincronización con Google Drive.
- `config.js`: ID de cliente de Google (no es secreto).

## Probar en la computadora

```
python3 -m http.server 5173
```

y abrir http://localhost:5173
